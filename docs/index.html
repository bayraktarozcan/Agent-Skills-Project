Why Agent Skills?

Neden Agent Becerileri?

A curated, categorized, trust-ranked ecosystem — not a raw dump.

Küratörlü, kategorize edilmiş, güven sıralaması olan bir ekosistem — ham bir yığın değil.

⚡

One-command install

Tek komutla kurulum

Clone pinned repos, extract SKILL.md files, resolve collisions, and install to ~/.agents/skills/ with one Python command.

Sabit depoları klonlar, SKILL.md dosyalarını çıkarır, çakışmaları çözer ve tek Python komutuyla ~/.agents/skills/ altına kurar.

🏷️

Ten functional categories

On işlevsel kategori

Core, AI & LLM, Cloud & Backend, Frontend & UI, Mobile, Security, Testing, Content, Community, Risk.

Çekirdek, AI & LLM, Bulut & Arka Uç, Ön Yüz & Arayüz, Mobil, Güvenlik, Test, İçerik, Topluluk, Risk.

🔒

Immutable source pins

Değişmez kaynak pinleri

Every source is pinned to a reviewed commit SHA. A weekly workflow proposes controlled updates, so installs stay reproducible and current.

Her kaynak gözden geçirilmiş bir commit SHA'sına sabitlenir. Haftalık iş akışı kontrollü güncellemeler önerir; kurulumlar yeniden üretilebilir ve güncel kalır.

🔄

Collision-safe deduplication

Çakışmaya güvenli tekilleştirme

Identical copies are merged. Different content gets a namespaced folder ordered by source trust, so no skill is silently overwritten.

Özdeş kopyalar birleştirilir. Farklı içerik, kaynak güven sırasına göre adlandırılmış bir klasörde korunur; hiçbir beceri sessizce üzerine yazılmaz.

📦

Provenance and digests

Köken ve özetler

Each install records the resolved commit, source tier, and SHA-256 digest of every skill. --check reports later drift.

Her kurulum, her beceri için çözümlenen commit'i, kaynak düzeyini ve SHA-256 özetini kaydeder. --check sonraki sapmayı bildirir.

📋

Bilingual, dependency-free

İki dilli, bağımlılıksız

English and Turkish CLI and GUI. Standard library only — no pip install, no third-party packages.

İngilizce ve Türkçe CLI ve GUI. Yalnızca standart kütüphane — pip kurulumu yok, harici paket yok.

Quickstart

Hızlı Başlangıç

Requirements: current Python 3, Git, and optional tkinter for the GUI.

Gereksinimler: güncel Python 3, Git ve GUI için isteğe bağlı tkinter.

Python 3 
# Clone the project# Projeyi klonlayın
❮ git clone https://github.com/bayraktarozcan/Agent-Skills-Project.git
❮ cd Agent-Skills-Project

# Recommended: 35 curated repos# Önerilen: 35 küratörlü depo
❮ python skills.py

# Trusted suite: K1-K8, 41 repos# Güvenli paket: K1-K8, 41 depo
❮ python skills.py trusted

# Everything: K1-K10, 50 repos# Tümü: K1-K10, 50 depo
❮ python skills.py all

# One category, preview, real content, or GUI# Tek kategori, önizleme, gerçek içerik veya GUI
❮ python skills.py K2
❮ python skills.py --dry-run
❮ python skills.py --inspect
❮ python skills.py --gui

✔ Skills installed toBeceriler kuruldu: ~/.agents/skills/
Turkish aliasesTürkçe takma adlar 
# Turkish aliases work in English too:# Türkçe takma adlar İngilizce arayüzde de çalışır:
❮ python skills.py onerilen    # Recommended profile (default)# Önerilen profil (varsayılan)
❮ python skills.py guvenli     # Trusted profile (K1-K8)# Güvenli profil (K1-K8)
❮ python skills.py tumu        # All categories (K1-K10)# Tüm kategoriler (K1-K10)
❮ python skills.py --lang tr   # Switch interface to Turkish# Arayüzü Türkçeye geçirir

Repo scopes: recommended 35, trusted 41, all 50. Specialization profiles: temel 227, dengeli 360, tam 1001 skills. Preview with --dry-run, measure real content with --inspect.

Depo kapsamları: önerilen 35, güvenli 41, tümü 50. Uzmanlaşma profilleri: temel 227, dengeli 360, tam 1001 beceri. --dry-run ile önizleyin, --inspect ile gerçek içeriği ölçün.

Built for trust

Güven için tasarlandı

A SKILL.md file carries instructions that can shape agent behaviour. Source trust is enforced mechanically, not merely asserted.

Bir SKILL.md dosyası ajan davranışını etkileyebilen talimatlar taşır. Kaynak güveni yalnızca iddia edilmez, mekanik olarak zorunlu kılınır.

🛡️

Fail-closed paths

Kapalı devre yollar

Symlinks and junctions are rejected; every candidate must resolve inside its clone root before it is read, rewritten, copied, or quarantined.

Sembolik bağlantılar ve junction'lar reddedilir; her aday okunmadan, düzeltilmeden, kopyalanmadan veya karantinaya alınmadan önce klon kökü içinde çözümlenmelidir.

🔗

Measured, not estimated

Tahmin değil, ölçüm

--inspect clones a source and reports real names, sizes, and digests. CI verifies a real install and an all-source inventory baseline.

--inspect bir kaynağı klonlayıp gerçek adları, boyutları ve özetleri bildirir. CI gerçek kurulumu ve tüm kaynakların envanter tabanını doğrular.

🧪

Continuous verification

Sürekli doğrulama

Unit tests, named invariant checks, and required gates run on every pull request; a weekly workflow proposes reviewed pin updates.

Birim sınamaları, adlandırılmış invariant kontrolleri ve zorunlu kapılar her PR'da çalışır; haftalık iş akışı gözden geçirilmiş pin güncellemeleri önerir.
